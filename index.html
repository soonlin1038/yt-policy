本頁說明「林麻-醫學冷知識研究室」使用的內部發布工具「Wee Reels Publisher」(以下稱「本工具」)如何使用 Google 與 YouTube 的資料。本工具只供頻道管理者本人使用,不對外提供服務、不開放其他使用者登入。

隱私權政策

用途。本工具使用 YouTube Data API,只做以下幾件事:把頻道管理者自己製作的短影音上傳到自己的 YouTube 頻道、設定標題與說明、設定公開或排程時間、查詢自己頻道已上傳的影片清單(避免重複上傳),以及刪除或修改自己頻道尚未公開的影片。

取得的資料。本工具只取得授權帳號自己頻道的基本資料(頻道名稱與編號)與該頻道影片的標題、編號、公開狀態。本工具不讀取觀眾的個人資料、留言者資料、訂閱者名單或任何其他使用者的資料。

保存方式。OAuth 授權憑證以加密方式存放在頻道管理者自己的 Google Cloud Secret Manager,不寫在本機檔案,也不提供給任何第三方。影片編號與發布時間記錄在管理者自己的檔案中,只用於追蹤發布狀態。

分享與販售。本工具不分享、不出售、不轉移任何經由 YouTube API 取得的資料,也不用於廣告。

撤銷授權。可隨時到 Google 帳戶「第三方存取權」 移除本工具的存取權;移除後本工具即無法再存取頻道。

Google 隱私權政策。本工具使用 YouTube API 服務,使用時同時適用 Google 隱私權政策。

服務條款

使用本工具即表示同意 YouTube 服務條款。本工具為頻道管理者自用,不提供給第三方使用;頻道影片內容為醫學史與醫學知識介紹,不構成個人醫療建議,身體狀況請諮詢醫師。
